# Contributing to Beginner Python EDA

Thank you for wanting to contribute! Here is how you can help:

### How to Contribute
1. **Find an Issue:** Look at our open issues list or create a new one to suggest a change.
2. **Fork the Repo:** Click the 'Fork' button to create a copy under your account.
3. **Make Changes:** Add your data notebooks, clean up data sets, or fix formatting.
4. **Submit a PR:** Open a Pull Request back to this repository explaining your updates!

### Contribution Ideas
* Add clean `.csv` datasets for practice.
* Build beginner-friendly Jupyter Notebook templates.
* Fix typos in documentation.
